ECFF Theater Ops: a standalone app you can install on a phone (PWA)

Host this folder on any static HTTPS host (GitHub Pages, Netlify Drop, Cloudflare Pages).
On the phone, open the link in Safari (iPhone) or Chrome (Android) and choose Share > Add to Home Screen.
It installs as a full-screen app with its own icon, uses the phone layout automatically, and works offline.

In this standalone version, data is saved on each phone separately (use More > Import / export > Backup to move it).
For one schedule shared live across your whole crew, use the claude.ai version.
